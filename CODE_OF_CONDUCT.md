# Community conduct

Everyone participating in issues, reviews, discussions or project events must
communicate respectfully. Constructive disagreement and good-faith questions are
welcome. Harassment, threats, discriminatory abuse, sexualized attention, personal
attacks and publication of another person's private information are unacceptable.
Apply the same standards when representing the project elsewhere.

Repository administrators enforce this policy. Report a public incident using its
GitHub report controls. For a confidential project report, request a private
channel from a repository administrator without posting sensitive details; use
GitHub's abuse-reporting channel if an administrator is involved or direct contact
is unsafe. Do not post a victim's identity or private evidence in a public issue.

Administrators preserve confidentiality where practical, review available evidence
fairly and disclose conflicts of interest. Responses may include a private warning,
a request to edit/remove material, restricted participation or a temporary or
permanent ban, proportionate to severity and repeated behavior. A participant may
request reconsideration with new evidence; an uninvolved administrator should
review it when one is available. No additional moderator is claimed by this policy.
