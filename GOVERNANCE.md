# Governance and maintenance

dbus-emporia-vue uses maintainer-led review through the public GitHub repository.
Repository administrators are accountable for access and release permissions;
maintainers with write access review and integrate changes. These roles describe
responsibilities, not an assertion that any particular additional person has
accepted a role. Current access is administered in GitHub, not granted by this file.

## Decisions and responsibilities

Contributors open issues or pull requests describing a concrete problem, evidence
and compatibility impact. Maintainers seek agreement in that public discussion.
If disagreement remains, the repository administrator records the decision and
its rationale there. Security reports follow SECURITY.md until disclosure is safe.
No AI assistant or approval bot is an independent human decision maker.

Reviewers check tests, security boundaries, documentation and license compatibility.
Release maintainers check the exact source, required CI, release notes, artifact
integrity and applicable acceptance evidence before using the normal release flow.
Administrators maintain least-privilege access, review credentials after personnel
changes, and arrange recovery of the repository and publishing credentials.
Contributors retain responsibility for the rights to submitted material; a
contribution must be compatible with LICENSE. No retrospective DCO sign-offs or
CLA approvals are asserted.

## Continuity: not yet established

On 2026-10-12 the owner confirmed that no continuity mechanism is in place for
this project. The owner must identify an authorized person
or lawful escrow/recovery arrangement, record how repository and release access
can be recovered within one week, and verify it without publishing secrets.
The arrangement may be recorded privately with a public non-sensitive statement.
Until that happens, OpenSSF access_continuity is unmet and no bus-factor claim
is made. Copying this policy or naming a bot does not satisfy that requirement.

On the same date the owner confirmed no reports outside GitHub for this project
in the preceding 12 months. GitHub report history is reviewed separately. Personal
security-knowledge attestations require the owner's actual confirmation; another
repository's answers do not transfer.
